# MIRVEX

MIRVEX — видеоплатформа с обычными видео и вертикальными Shorts.

## Стек
- React
- Vite
- Lucide
- Адаптивный интерфейс на русском языке

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```

Текущая версия — демонстрационный интерфейс с тестовым контентом. Реальный видеохостинг, авторизация, загрузка и хранение видео подключаются отдельными этапами.
